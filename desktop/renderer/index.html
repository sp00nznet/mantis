Swarm

        
When on, plain prompts run through the multi-provider swarm (PLAN → EXPLORE → CODE → REVIEW). Needs at least 2 providers with API keys.

External Agents

        
Other agentic CLIs Mantis can delegate a turn to. Mantis becomes a passthrough — it doesn't see their tool calls, just the streamed reply. Detected via your PATH.

        

        
      


      

        
Local backends

        
URLs for local model servers. Leave blank to use the default. Ollama models appear in the Model dropdown when "Local (Ollama)" is the active provider.
